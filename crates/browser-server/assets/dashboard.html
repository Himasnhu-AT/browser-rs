Watch it work, then take over

  1. Watch. Open a session below to see the browser your agent is driving, live.
  2. Take control. One button. Until you press it, your clicks go nowhere — a stray click while the agent is mid-task is a real way to lose work.
  3. Log in by hand. Type the password yourself. Solve whatever the site asks for.
  4. Release. The agent carries on in the same session, already authenticated.

Each session keeps its own persistent Chromium profile directory. That directory is what holds the cookies, so a login survives the next request, the next hour and a restart of this server.
